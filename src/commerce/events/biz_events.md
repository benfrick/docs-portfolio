## <a name="#overview"></a>Overview

The <b>Analytics Pipeline v2 API</b> is your single destination to record analytics events, helping user experiences and web services to track consumer and application behavior.

Analytics events sent to this API are transformed and sent to multiple downstream systems/partners in real-time, allowing many needs to be fulfilled by sending a single event.

![](https://nde-devportal-docs.niketech.com/images/analytics/events.png)

Here are just a few ways in which analytics event data can be used:

<i class="g72-check"></i> **Track the success of marketing campaigns via tags or attribution**

<i class="g72-check"></i> **Monitor user traffic and conversion metrics**

<i class="g72-check"></i> **Track the success of new features (A/B testing)**

<i class="g72-check"></i> **Alert on traffic anomalies**

## <a name="#features"></a>Features

<i class="g72-thumbs-up"></i> **Send once, analyze many ways**. One integration can unlock many analytics possibilities.

<i class="g72-thumbs-up"></i> **Server-side and Nike-authored**. More customizable to your needs compared to a proprietary, client-side analytics solution

<i class="g72-thumbs-up"></i> **Easily add future integrations with other partners**. When additional partners are added, you reap the benefit without the extra work.

## <a name="#considerations"></a>Considerations

**Easy Adoption**

It's easy to start sending your events to Analytics Pipeline. There are no prerequisites, so start now!

**Reliable and Scalable**

Nike services are built for reliability and scalability, reaping the benefits of cloud network architecture as the backbone of our services.

**The Latest Web API Standards**

Join the web API economy by using the common language of the internet to interact with Nike services. Your developers will be familiar with issuing JSON-formatted requests to Nike's REST web services using the standard HTTP web protocol.
