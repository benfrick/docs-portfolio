Developer's Guides

Nike Developer’s Guides provide practical guidance and business context on using Nike’s API toolset. The Developer’s Guide for a given domain supplements the API reference documentation that the teams within a domain create. Each Developer’s Guide addresses real-world use cases, and often makes the connections across domains, helping developers to solve complex problems within the Nike ecosystem.

Cart and Checkout

DEVELOPER’S GUIDE: BUY DOMAIN

Use the Buy APIs to allow consumers to add Nike products and services to their cart, choose shipping options, and complete their order.

DEVELOPER’S GUIDE: PAYMENT DOMAIN

Provide consumers a list of valid payment options, allocate payment types across their order, and validate and authorize their payment, all with the Payment APIs.
