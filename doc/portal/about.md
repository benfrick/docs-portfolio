# About This Site

---

- **WHAT**: Technical writing portfolio focused on REST APIs and other technology products

- **WHY**: Demonstrate skills and experience and share a template of a working doc site

- **WHO**: Recruiters, hiring managers, tech writers, developers

## How Do I Get Started?

Recruiters/Hiring Mgrs: Explore the sidebar and navigate to the docs samples

Tech Writers/Devs: In the source, check out the README.md and the /docs-portfolio/doc/templates folder

## What Types of Content are Available?

The following table describes ALL types of content available,
who the primary audience is for each, and provides links to an example.

| Doc Type          | Description                                                                                                           | Audience                               | Example                                                                              |
|-------------------|-----------------------------------------------------------------------------------------------------------------------|----------------------------------------|--------------------------------------------------------------------------------------|
| Overview          | Gives an overview of a domain or set of APIs, and lists the use cases covered in the corresponding developer's guides | Product Managers, Engineering Managers | [Cart & Checkout Overview](/docs-portfolio/doc/commerce/checkout/overview-checkout.html)            |
| Developer's Guide | Detailed implementation steps for specific API use cases                                                              | Developers                             | [Product Feeds Developer's Guide](/docs-portfolio/doc/commerce/product/use-product-feeds.html)      |
| Reference Guide   | Reference information that is relevant to API integration                                                             | Developers                             | [Circuit Breaker Best Practices](/docs-portfolio/doc/commerce/reference/caller-best-practices.html) |
| Templates         | Templates for writing your own docs                                                                                   | Developers, Product Managers           | See `/docs-portfolio/doc/templates` in the source                                                   |

**Developer's Guides** on this site:

- Provide context about how an API fits into the larger ecosystem
- Step through related use cases, including those that span multiple domains
- Spotlight how the API portfolio can be used to build features to elevate the consumer experience
- Quickly answer your questions through self-service to shorten the API learning curve

**Overviews**, in contrast, are geared toward Product Managers, Engineering Managers, and others who don't write code,
but who might be involved with the solution planning and design.
