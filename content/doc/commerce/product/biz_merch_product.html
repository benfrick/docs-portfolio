Overview

Nike products drive the e-commerce and brand experience

The Merchandised Product API provides access to product content and pricing that you can use to tailor your Nike experience to a global audience, making customers feel like they are shopping locally. The number of ways to slice the data is limitless.


Features

The Merchandised Product API supports the US, Japan, China and European Union geographies, allowing you to reach a wide customer base.

Here is the kind of data accessible to you by using the Merchandised Product API.

Merchandised Products: Provides detailed information about the product such as style, color, where it can be sold, and if it can be customized.

Merchandised SKUs: Gives localized size data, the product a SKU is tied to, where it can be sold and much more.

Merchandised Prices: Presents a complete picture of pricing for a product including full price, sale price, employee price, currency and promotion information.

Merchandised Value-added Services: Includes add-ons associated with a product such as gift wrap, gift bags and personalization.

Product Content: Lists localized content for a product including title, subtitle, description and color to give customers a custom-tailored product experience.

Use the Merchandised Product API to tell your Nike product story.

Considerations

Reliable and Scalable

Nike services are built for reliability and scalability, reaping the benefits of cloud network architecture as the backbone of our services.

The Latest Web API Standards

Join the web API economy by using the common language of the internet to interact with Nike services. Your developers will be familiar with issuing JSON-formatted requests to Nike's REST web services using the standard HTTP protocol.
