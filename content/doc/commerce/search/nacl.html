NDe Admin Client Library

 

The NDe Admin Component Library (NACL) is a modular and flexible toolkit of user interface components that you can use in your internal Nike applications. Plug in just the pieces you need to quickly build your UI and foster a consistent look and feel across Nike applications. Installation is easy and you get a comprehensive set of functionality right out of the gate with no configuration required. Require customized styles? NACL supports that too with only one line of code.
