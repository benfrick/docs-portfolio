Authentication and Identification

Certain NDe endpoints require that the caller prove its identity and that it is authorized to call the endpoint. This is done by generating a time-sensitive JSON Web Token (JWT), passing the JWT in the request to the endpoint, and validating it. Visit the Nike JWT Reference Guide for more information.
