Glossary of Terms

TermDefinition
A/B TestIn web analytics, a controlled experiment with two variants of user experience intended to measure an increase in a desired outcome based on a change to the UX (e.g. conversion)
APIApplication Programming Interface
API.mdThe 'contract' document of an API, which details the endpoints offered along with request and response schemas
Authorization (of payment)Temporary hold on funds in a customer's account for a future charge
CartThe virtual shopping cart used by shoppers to collect and compare items for purchase
CheckoutA collection of data describing what may become a customer order
CORSCross-Origin Resource Sharing
cURLA computer software project providing a library and command-line tool for transferring data using various protocols. Can be used to execute HTTP requests from the command line
Deferred PaymentThird-party bank through which a customer pays for their Nike order after it is placed
FapiaoTax-related invoice offered to China customers only
GTINGlobal Trade Item Number. Nike leases a block of these numbers. They are not unique, as Nike recycles them for a new season of products.
HTTPHyperText Transfer Protocol, the standard language of the internet
Image BaseFull path to a product image in an image set. This does not include resizing parameters.
Image SetSet of product images stored in Scene 7 representing different views of the product. Build the URI to the product image using domain + company + view from the list image results call.
JWTJSON Web Token, used for authorization purposes in API requests
LaunchThe release of a new product for sale in a Nike digital or retail experience
Master ProductA Nike iD product that has skus and is purchasable.
Merch GroupMerchandising Group representing a Nike geographical region. See a list of supported Merchandising Groups in the Enumerations section of the Merchandised Product service.
Nike iDNike's platform for shoppers to customize the look of their products
Nike UPMIDUnique Universal Profile Management ID used to identify the user as a logged in, registered Nike member
Prebuild ProductA non-purchasable Nike iD product that has no skus. Each Prebuild product is associated to one Master product that is purchasable.
ProdigySystem of record for all product data. All products are merchandised in this system and flow into the Merchandised Product database when they are published in Prodigy.
SegmentAnalytics API and customer data platform. One of many downstream integrations from Nike's Analytics Pipeline API
SEOSearch Engine Optimization. The process of maximizing visitors to a website by ensuring it appears high on the list of results returned by a search engine.
SEO slugShort text for search engine optimization, e.g. "tiempo-legend-6-totti-gladiator"
SKUStock Keeping Unit, a unique identifier for the combination of style, color, and size of a Nike product. A product has one or more SKUs. A SKU represents one size and has inventory.
SLAService Level Agreement. The Response Time and Requests Per Second guarantees made by an API
SNKRSA Nike app for web, iOS, and Android focused on making newly-launched and limited release products available for purchase
SplunkLogging application used by Nike
Trace IDA unique identifier passed from API to API to trace the path of a request using logging
URIUniversal Resource Indicator
URLUniveral Resource Locator
UUIDUniversal Unique Identifier
VASValue-Added Service associated with a product in a checkout. Gift wrap and the ability to customize a product are examples of VAS
PCI-DSSPayment Card Industry Data Security Standard provides secure standards for handling Credit Card data. All Nike CiC payment services are PCI-DSS compliant.
Void (of payment)Reverses a successful payment authorization
