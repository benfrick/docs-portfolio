NDe Developer's Guides

NDe Developer’s Guides provide practical guidance and business context on using its API toolset. The Developer’s Guide for a given domain supplements the API reference documentation that the teams within a domain create. Each Developer’s Guide addresses real-world use cases, and often makes the connections across domains, helping developers to solve complex problems within the Nike ecosystem.

Product Data

DEVELOPER’S GUIDE: MERCHANDISED PRODUCT API

Dig into Nike product, SKU, price, image and content information with the Developer’s Guide: Merchandised Product API to drive your brand and e-commerce experience.

Product Data: Related Information

  • REFERENCE GUIDE: MERCHANDISED PRODUCT FIELDS: Use this guide as a reference to Prodigy-assigned values for merchandised products and services such as supported product status codes, merchandising groups, product types and more.
  • DEVELOPER’S GUIDE: PRODUCT FEEDS API: Access Nike digital product data and content in the form of Cards, Threads, and Feeds.
  • CAPI MIGRATION GUIDE: The Commerce API (CAPI) is a legacy API that aggregates the data necessary for many existing experiences and tools to use product, search, and inventory data. The Commerce API is deprecated in favor or cloud-based APIs. The Migration Guide helps existing consumers to map the journey from CAPI to Cloud.
  • BUSINESS GUIDE: MERCHANDISED PRODUCT API: Target your customers effectively by taking advantage of the rich product and pricing data set offered by the Merchandised Product API.
