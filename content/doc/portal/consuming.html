Authentication and Identification

Clients must be authenticated and authorized to call certain NDe endpoints. This is done through the use of a JSON Web Token (JWT). The client generates and signs the JWT, passes the JWT in the request to the service, and the service validates it with the client's public key. Visit the JWT Getting Started Guide and Nike JWT Reference Guide for more information.
