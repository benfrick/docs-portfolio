NDe Doc Team Services

Hi, we are the NDe Doc Team! We document technologies for the Nike Developer Portal and more, in order to enhance the developer experience.

The documentation serves four audiences:

  1. New Developers looking to discover and learn the fundamentals
  2. Experienced Developers fixing a bug or implementing a new feature who need quick, specific answers
  3. Product teams seeking to solve business problems
  4. Decision Makers seeking to add business value

What We Do

 Write the Docs

Need new content from scratch? We can create any of the following for you:

  • User Guides
  • UX Integration Guides
  • Product Overviews
  • Tutorials
  • How-to videos
  • FAQs
  • Technical Reference Guides

We use a Doc Lifecycle process to create and maintain content.
