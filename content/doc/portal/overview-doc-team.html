Hi, we are the NDe Doc Team! We document technologies for the Nike Developer Portal and more, in order to enhance the developer experience.

What We Do

 Write the Docs

Need new content from scratch? We can create any of the following for you:

  • User Guides
  • UX Integration Guides
  • Product Overviews
  • Tutorials
  • How-to videos
  • FAQs
  • Technical Reference Guides

We use a Doc Lifecycle process to create and maintain content.

 Edit the Docs

Have content that is outdated or that needs to be edited for style and/or content?

See the NDe Doc Style Guide to learn about some of the writing standards that we use.

 Publish the Docs

Have finished documentation and need help publishing it to the developer portal or creating a PDF? We can help!

 Self-Service Doc Updates

If you have existing content on the Developer Portal, you can update it yourself directly in our GitHub repo.

At minimum, you need to be able to write in Markdown, and coordinate with us to publish the changes.

See here for details about self-service doc updates.
